# AURA — Luxury Gastronomy & Artisanal Café

A premium restaurant and café website concept focused on luxury visual design, responsive layouts, and interactive hospitality experiences.

## ✨ Features

* Premium luxury UI
* Responsive design
* Interactive menu filtering
* Private event cost calculator
* Reservation interface
* Animated statistics
* Particle background
* 3D-style hero interaction
* Cursor effects and micro-interactions

## 🛠️ Built With

* HTML5
* Tailwind CSS
* JavaScript
* HTML Canvas
* Google Fonts
* Lucide Icons
